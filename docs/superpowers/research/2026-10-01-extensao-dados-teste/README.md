# Pesquisa: extensão de dados de teste (2026-10-01)

Material da pesquisa que embasa `docs/superpowers/specs/2026-10-01-extensao-dados-teste-design.md`. São protótipos que rodaram e passaram, e não código de produção. O plano **porta** esse código para o repo, não reescreve do zero.

| Pasta             | Conteúdo                                                                                                                                                                                                                                         |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `relatorios/`     | Os 5 relatórios (`wxt`, `geradores`, `deteccao`, `design`, `repo`) e o `critic`, que cruza os cinco e resolve as contradições (C1–C18) e as lacunas (G1–G21). Marcação: **[V]** verificado, **[A]** suposto.                                     |
| `geradores/`      | Os 15 módulos geradores com testes Jest (172 passando). `viacep.json` guarda as respostas do ViaCEP que validam os 34 CEPs. `crossval.mjs` faz a validação cruzada com bibliotecas externas. `sketchbugs.mjs` mede os bugs do `gen()` do design. |
| `deteccao/`       | Classificador `campos.ts`, formatação `formatar.ts` e camada DOM `content.ts`, com 103 testes (`node:test`, falta portar para Jest). `paginas/` tem as páginas do laboratório: cadastro realista com honeypot, iframes e página longa.           |
| `popup/`          | Componentes do popup sobre o `@piluvitu/ui`, medidos pixel a pixel contra o design (`PopupShell`, `Dados`, `Estados`, `Marca`, `tipografia`, `style.css`, `tema.ts`).                                                                            |
| `aviso/toast.css` | CSS do aviso na página (1f), testado numa página hostil dentro de Shadow DOM.                                                                                                                                                                    |
| `icones/`         | SVGs do ícone 1i: 16 px ajustado ao pixel e 32/48 px redesenhados com retângulos em pixel inteiro.                                                                                                                                               |
| `integracao/`     | Workspace `apps/extensao` verificado de ponta a ponta (instalação pnpm, `tsc`, ESLint, Vitest, build com gate, Storybook, Playwright).                                                                                                           |
| `mecanica-wxt/`   | Sonda da mecânica MV3: injeção em runtime, atalho, menus, armazenamento, aviso em shadow root e E2E com a extensão carregada.                                                                                                                    |
