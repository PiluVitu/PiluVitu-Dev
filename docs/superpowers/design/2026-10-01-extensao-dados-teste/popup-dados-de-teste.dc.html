Regras

Contorno, não borda. outline não ocupa espaço, então nada no site se mexe. Ciano sólido = preenchido; âmbar tracejado = não reconhecido.

Some sozinho. O aviso fica 4 s (a barra fina mostra o tempo) e pausa com o mouse em cima. Os contornos saem junto, ou no primeiro clique dentro de um campo.

Isolado. O aviso vive num Shadow DOM com position: fixed, então o CSS do site não o afeta nem é afetado.

Alt+Shift+P: P de preencher. Não colide com atalhos do Chrome; no Mac aparece como ⌥⇧P.

Ctrl+Shift+Y: livre em todos os sistemas, mas sem mnemônico.

Alt+Shift+F: F de fill. Alguns editores web usam para formatar.

Qualquer um pode ser trocado em chrome://extensions/shortcuts; o link "alterar" do rodapé abre essa página.
